# תיק העבודות של מוריה

## איך פותחים
לחיצה כפולה על `start_portfolio.bat`. השרת עולה והאתר נפתח בכתובת http://localhost:5500.
כדי לסגור, סוגרים את החלון השחור.

## איפה משנים כל דבר
| מה | איפה |
|---|---|
| כל הטקסטים: שם, תיאור, כישורים, פרויקטים, ניסיון, קישורים | `assets/js/data.js` |
| תמונת פרופיל | שמים קובץ בשם `profile.jpg` בתיקייה `assets` (עד שיש תמונה, מוצגות האותיות MD) |
| קורות חיים | `assets/resume.pdf` (כרגע עותק של `Moria Deri- CV 2026.pdf`) |
| תמונה לפרויקט | מוסיפים `image: "assets/projects/שם.png"` לפרויקט ב-`data.js` |
| קישור GitHub / Live Demo | `github` / `demo` בפרויקט (ריק = הכפתור לא מוצג) |
| עיצוב וצבעים | `assets/css/style.css` (המשתנים בראש הקובץ) |
